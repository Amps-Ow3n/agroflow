# Feature 21 — Uganda Privacy/Security Requirements Mapping

This is an engineering mapping, not a legal-compliance certification.

## Uganda Data Protection and Privacy Act, 2019 / Regulations, 2021

Relevant engineering themes: lawful/fair processing, purpose limitation, data minimisation, security safeguards, retention governance, data-subject rights, breach handling, processor governance and transfer considerations.

AgroFlow controls supporting these themes: scoped identity access, privacy notice, authenticated personal-information access, least-privilege organization authorization, controlled document access, minimised logging, secret management, security monitoring/logging, incident-response procedure and retention governance documentation.

## Computer Misuse Act

Relevant engineering themes: protection of information systems against unauthorized access, abuse and misuse. AgroFlow controls include authentication, authorization, input validation, CSRF protection, rate limiting, safe document paths, security headers and auditability.

## Legal status

AgroFlow must not be represented as legally compliant solely from these controls. Actual obligations depend on the operator, processing activities, deployment, contracts, registration/DPO position, data flows and applicable legal advice.
